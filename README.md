# light-sphere-picker
Light Sphere Picker for Krita 🎨

An interactive 3D lit sphere docker plugin for Krita to study values, lighting, and color harmonies in real time.

## Features / Características
- 💡 **Interactive Light & Bounce**: Drag with Left Click to move the key light, Right Click to move the bounce light.
- 🎨 **Real-time Krita Sync**: Automatically updates the sphere when picking colors in Krita.
- 🌈 **Auto Complementary Shadows (Hue-Shift)**: Physically based color shifting for rich shadows.
- 🧪 **Material Modes**: Switch between Plastic/Matte and Skin (Organic) with independent color memory.
- 🎯 **Quick Palette**: Click on Light, Mid, Shadow, or Bounce swatches to paint directly with that tone.
- 🌍 **Bilingual**: Automatic English & Spanish UI.

## Installation / Instalación
1. Download `LightSpherePicker.zip` from the **Releases** section.
2. In Krita, go to: `Tools > Scripts > Import Python Plugin...` and select the `.zip`.
3. Restart Krita.
4. Enable the docker from: `Settings > Dockers > Light Sphere` (or *Esfera de Luz*).
